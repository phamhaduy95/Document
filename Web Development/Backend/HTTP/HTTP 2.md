HTTP/2 separates HTTP messages into binary encoded frames, with each frame
type having a purpose in the protocol—for example, DATA (HTTP message body),
HEADERS (HTTP message headers), SETTINGS (various HTTP/2-related settings),
or GOAWAY (intent to not start any new streams, or to signal serious errors).
