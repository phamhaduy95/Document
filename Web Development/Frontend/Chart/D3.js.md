#### Introduction
`D3.js` is a popular library which provides set powerful tools for building chart or diagram using `SVG`. 
#### Prerequisites 
D3 has quite steep learning curve that requires its developers must be familiar with `SVG` and strong web foundations such as HTML, CSS, JavaScript. Beside technical side, D3 developer also needs awareness of data visualization,
#### Techniques
**Optimize `DOM` Manipulation**: Minimize the number of `DOM` elements created and manipulated in your visualization. Use `D3.js` selection methods like `enter()` and `exit()` to efficiently update the `DOM` based on changes in the underlying data, rather than recreating elements from scratch

#### Plugins
`d3-vs` (D3 Virtual Scroll) : library for implementing virtual-scroll for `d3` chart.
