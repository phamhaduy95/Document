AWS cung cấp các giải pháp và service sau đây giúp danh nghiệp xây dưng và phát triển các ứng dụng AI và Machine Learning
1. **Amazon SageMaker**
	- **Purpose**: A fully managed platform for building, training, and deploying ML models at scale
	- **Use Cases**: Predictive analytics, fraud detection, recommendation systems, computer vision, NLP
	- **Best For**: Developers and data scientists needing end-to-end ML workflows.
2. **AWS bedrock**
	- **Purpose**: A managed service for building generative AI applications using foundation models (FMs).
	- **Use Cases**: Chatbots, content generation, text summarization, image generation.
	- **Best For**: Developers building generative AI apps without managing infrastructure.
3. **Amazon Comprehend**
	- **Purpose**: NLP service for extracting insights from text.
	- **Use Cases**: Social media analysis, document processing, customer feedback analysis.
	- **Best For**: Adding text analytics to applications.
4. **AWS DeepLens**
	- **Purpose**: A deep learning-enabled video camera for developing computer vision applications.
	- **Use Cases**: Smart home devices, retail analytics, security monitoring.
	- **Best For**: Developers experimenting with edge-based vision AI.

Amazon Transcribe: Converts speech to text.
Amazon Translate: A neural machine translation service that delivers highquality language translation
