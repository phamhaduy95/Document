#### Data Encryption

Ngoại trừ public S3 bucket, ta nên đảm bảo các private bucket được mã hóa nhằm tăng tính bảo mật cho data. việc mã hóa giữ liệu cho S3 có thể thực hiện ở server-side vả client-side.

##### Client-side encryption

Ta có thể tiến hành mã hóa các object bằng dịch vụ KMS trước khi upload lên S3 thông qua AWS SDK hoặc CLI.

##### Server-side encryption

- **Amazon S3-Managed Keys (SSE-S3)** - Đây là phương thức encryption mặc định của S3. S3 thực hiện tự động toàn bộ quy trình encrypt và decrypt object.
- **AWS KMS-Managed Keys (SSE-KMS**) -cho phép user chọn key từ dịch vụ KMS.
- **Customer-Provided Keys (SSE-C)**: You can use SSE with a customer-provided encryption key. With each request, the encryption key is provided to AWS, and Amazon S3 manages the encryption and decryption of S3 objects by using the supplied key

x-amz-server-side-encryption: AES256

x-amz-server-side-encryption-aws-kms-key-id: <KMS Key ARN or Alias>      # optional
