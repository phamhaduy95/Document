**AWS Secrets Manager** is a fully managed service that helps you securely store, manage, and retrieve sensitive data such as database credentials, API keys, and other secrets.

Important features:
- Stores secrets in encrypted form using **AWS Key Management Service** (KMS).
- Supports custom secret sand predefined formats for database credentials 
- Support **automatic Rotation** on schedule
- Supports **multi-Region secret replication**, allowing secrets to be replicated across multiple AWS Regions
- you can share secret with other AWS accounts via **Resource Access Managers**
