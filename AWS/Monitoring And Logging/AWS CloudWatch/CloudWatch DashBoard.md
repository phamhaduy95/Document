CloudWatch Dashboard 

- CloudWatch allows sharing dashboards directly from the console without requiring an AWS account. By entering the product manager’s email address, a shareable link is generated that provides read-only access to the specific dashboard.
- This feature supports **anonymous access** (no AWS account required) or access via AWS Single Sign-On (SSO) or IAM credentials, but for a non-AWS user like the product manager, the anonymous link is sufficient.
- The shareable link can be configured to require a password for additional security, ensuring controlled access.
