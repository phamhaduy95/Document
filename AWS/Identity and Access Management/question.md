sẽ có nhưng câu hỏi troubleshooting khi sử dụng các dịch vụ hay CLI của AWS. Nên lưu ý kỹ vấn đề này.

ví dụ như câu hỏi bên dưới
1. You make a request to describe voices offered by Amazon Polly by using the AWS CLI, and you receive the following error message:
    Could not connect to the endpoint URL
    https://polly.us-east-1a.amazonaws.com/v1/voices
    What went wrong?
    1. Your credentials have been rejected.
    2. You have incorrectly configured the AWS region for your call.
    3. Amazon Polly does not offer a feature to describe the list of available voices.
    4. Amazon Polly is not accessible from the AWS CLI because it is only in the AWS SDK.
