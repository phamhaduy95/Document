AWS Organizations cung cấp:
- centralize UI để organize security và service trên nhiều AWS accounts.
- create/deactivate/remove AWS account
- grouping nhiều AWS account khác nhau thành các Organization Units
- share resources cho nhiều AWS account thông qua AWS Resource Access Manager.
- consolidate billing và thực hiện trả phí cho nhiều account
- apply Service control policies (SCP) restrict which AWS services can be used within an AWS Organization

Audit, monitor, and secure all your environments for compliance and functional purposes. A single account’s CloudTrail service can be configured to watch events from  
your entire organization
