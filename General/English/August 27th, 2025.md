For caching to be as effective as possible, it should generally be the case that when you go to access a piece of data, it is already in the cache. To achieve this, a cache maintenance algorithm determines what to ***keep in the cache*** and  what to ***evict from the cache*** when new data needs to be brought in

When item di is presented, we can access it very quickly if it is already  
in the cache; otherwise, we are required to bring it from main memory into  
the cache and, if the cache is full, to evict some other piece of data that is  
currently in the cache to make room for di. This is called a ***cache miss***, and we  
want to have as few of these as possible
