`venv` is the **standard built-in Python module** used to create isolated **virtual environments**

why should use venv
- **Isolation:** Prevents conflicts that arise when different projects require different versions of the same package (e.g., Project A needs Django 3.0, while Project B needs Django 3.2).
- **Cleanliness:** Keeps your global Python installation clean of project-specific packages.
- **Permissions:** Allows you to install packages in a local directory without requiring administrative or root privileges
